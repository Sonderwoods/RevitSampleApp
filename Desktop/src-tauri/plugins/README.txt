Cloudburst plug-ins bundled with the desktop installer.

Revit\   Revit 2026 add-in. The setup program copies it to %AppData%\Autodesk\Revit\Addins\2026 when Revit 2026 is found.
Rhino\   Rhino 8 + Grasshopper as a Yak package. The setup program installs it with Rhino's Yak.exe when Rhino 8 is found.

To install by hand later: copy the contents of Revit\ into %AppData%\Autodesk\Revit\Addins\2026, and drag the .yak
file in Rhino\ onto a Rhino 8 window. If these folders are missing, this build was made without the plug-ins.
